# DJ Kennady

Личный сайт Егора Морозова: диджей DJ Kennady и бренд одежды ETIQET.
Одна страница, два языка, монохром, две 3D-сцены.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run verify   # проверка типов и тесты
npm run budget   # сборка + проверка бюджетов веса
```

## Где править контент

**Весь текст, все ссылки и все пути к файлам лежат в
[`src/content/content.ts`](src/content/content.ts).** Это единственный файл,
который нужно трогать, чтобы поменять наполнение сайта. Код править не надо.

Внутри два одинаковых по структуре блока — `ru` и `en`. Если добавляешь
что-то в один, добавь и в другой: тест `content.test.ts` следит, чтобы
наборы ключей совпадали и чтобы не было пустых строк.

## Куда класть файлы

| Папка | Что туда | Как попадает на сайт |
|---|---|---|
| `public/media/` | фото, видео, принты | путь вида `/media/shot-01.webp` в `content.ts` |
| `public/models/` | GLB-модель футболки | путь в `content.ts`, поле `etiqet.model` |
| `public/fallback/` | статичные рендеры сцен | `hero.webp` и `tee.webp`, подставляются на слабых устройствах |

Файла нет — сайт не ломается: на его месте остаётся ровный блок, а 3D-сцена
показывает ткань без принта. Поля `etiqet.model` и `etiqet.print` со
значением `null` — это нормальное состояние, а не ошибка.

## Что стоит знать про устройство

- Цвета заданы только четырьмя переменными в `src/styles/index.css`
  (`--bg`, `--fg`, `--muted`, `--line`). В компонентах цветов нет, и тест
  это проверяет.
- 3D грузится отдельным чанком и только на достаточно мощных устройствах.
  На слабых и при включённом «уменьшить движение» подставляются картинки
  из `public/fallback/`.
- Блок ETIQET — светлая панель со своей палитрой (класс `.day`), остальная
  страница остаётся ночной.
